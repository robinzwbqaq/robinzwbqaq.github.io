# Personal Academic Homepage

A responsive, single-page academic website for **Weibin Zeng**, built with plain HTML,
CSS, and JavaScript. No build step is required.

## Personalize

Before publishing, replace these placeholders in `index.html`:

- `your.email@example.com` with your email address
- `https://github.com/your-username` with your GitHub profile URL
- The short biography and paper descriptions, if you want more precise wording

## Preview locally

Open `index.html` directly, or run:

```bash
python3 -m http.server 8000
```

Then visit `http://localhost:8000`.

## Publish with GitHub Pages

1. Create a repository named `<your-username>.github.io`.
2. Copy the contents of this folder to the repository root.
3. Commit and push to the `main` branch.
4. In **Settings → Pages**, select **Deploy from a branch**, then choose `main` and `/ (root)`.

Your site will be available at `https://<your-username>.github.io`.
